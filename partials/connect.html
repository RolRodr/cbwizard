A Personal Access Token (PAT) is like a secure, temporary password created specifically for this app. It allows the app to perform actions on your GitHub account safely without needing your actual login password.

The token requires repo scope to fork and write to repositories.
How to create a Personal Access Token (Classic)
Note: We recommend using a Classic Token because Fine-grained tokens currently have API limitations when forking public repositories you don't own.
  1. Go to GitHub Settings > Developer Settings > Tokens (Classic) (opens in a new tab).
  2. Click "Generate new token (classic)".
  3. Give it a Note (e.g., "Wizard App").
  4. Select the repo scope (Full control of private repositories).
    • Required to fork the template and push content.
  5. Click "Generate token" and copy it here.
Don't worry. Your token is only ever stored in your browser.
